| Exploitation Fundamentals | <br>- Exploitation concepts: payloads, shells, exploits, and exploit reliability <br>- Using Metasploit Framework: modules, listeners, payloads, and post modules <br>- Buffer overflows and memory corruption basics (conceptual overview and safe demonstration) <br>- Safe exploitation practices and avoiding collateral damage <br>- Authentication bypass techniques, default credentials and weak crypto <br>- Hands-on lab: controlled exploitation with Metasploit on lab targets; capturing shells and documenting steps <br> | 4 |
| Web Application Hacking (OWASP Top 10 Focus) | <br>- Web application architecture, request lifecycle and common components <br>- Injection attacks (SQLi, Command Injection) — detection and exploitation <br>- Authentication and session management weaknesses <br>- Cross-Site Scripting (XSS), CSRF and other client-side attacks <br>- Insecure deserialization, broken access control and server-side vulnerabilities <br>- Using Burp Suite effectively: intercepting proxy, repeater, intruder, scanner basics <br>- Automated vs manual testing techniques and fuzzing approaches <br>- Hands-on lab: OWASP Top 10 practical exercise using vulnerable web apps (e.g., DVWA, Juice Shop) with Burp Suite and sqlmap <br> | 6 |

| Wireless and Mobile Security Basics | <br>- Wireless fundamentals: 802.11 overview, encryption types (WEP/WPA/WPA2/WPA3) and attack surface <br>- Assessing wireless networks: discovery, rogue APs, deauth attacks and WPA handshake capture <br>- Bluetooth and IoT/mobile considerations and common misuse patterns <br>- Tools for wireless testing: Aircrack-ng suite, Kismet and mobile-focused tools <br>- Hands-on lab: capture and analyze wireless traffic in a controlled environment; attempt WPA2 handshake capture and demonstrate deauth (lab-safe) <br> | 2 |
| Post-Exploitation, Privilege Escalation and Data Exfiltration | <br>- Post-exploitation objectives: persistence, credential harvesting, lateral movement and data staging <br>- Windows and Linux privilege escalation techniques and identification of privilege escalation vectors <br>- Credential dumping basics (LSASS, /etc/passwd shadow) and safe handling <br>- Maintaining access: backdoors, scheduled tasks, services and startup items (ethical considerations) <br>- Data exfiltration methods and minimizing detection <br>- Hands-on lab: perform post-exploitation tasks in lab, practice privilege escalation techniques and document findings <br> | 3 |
| Reporting, Remediation Guidance and Communication | <br>- Structuring professional penetration testing reports: executive summary, technical findings, risk ratings and remediation steps <br>- Creating reproducible test evidence: logs, screenshots, PoCs and safe artifact handling <br>- Delivering technical and non-technical briefings to stakeholders <br>- Remediation validation and retest recommendations <br>- Introduction to red/blue team collaboration and basic defensive controls to mitigate common attack patterns <br>- Hands-on: produce a sample finding report from lab exercise and present remediation recommendations <br> | 2 |
